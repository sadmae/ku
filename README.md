# Калькулятор устойчивости бизнеса

КУ-спрос, КУ-узлы и окупаемость решений. Исходные данные вводятся в боковой панели, расчёт выполняется локально.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/streamlit run app.py
```

Проверки:

```bash
.venv/bin/pytest
```

## Что считает

- **КУ-спрос** = расходы на продажи / выручка. Коридор: нижняя граница заменяет отток (`отток × клиенты × CAC / выручка`), верхняя равна `маржа × эластичность b`.
- **КУ-узлы**: уязвимость = потери в день × дней на замену. Доля допрасходов = допрасходы / выручка.
- **Окупаемость** = (предотвращаемые потери × вероятность) / затраты в день. Платить стоит, если окупаемость выше 2. Безопасная цена вдвое ниже ожидаемого эффекта.
- Кривая **π(M)** показывает вклад, если выручка меняется как `M` в степени `b`.

Кнопка «Пример Айнуры» подставляет эталонные данные кофейни. Тексты переключаются между русским и кыргызским. Сводка скачивается в CSV или PDF.
